# 🎓 Öğretmenler Odası - Modern Eğitim & Pedagoji Blogu

Öğretmenler için ders materyallerine, eğitim teknolojilerine, sınıfta yapay zekâ uygulamalarına ve pedagojik rehberlik içeriklerine kolayca erişebilecekleri modern, sade, şık ve responsive bir eğitim blogu platformu.

## ✨ Özellikler

- **🏠 Ana Sayfa:**
  - Karşılama ve arama Hero bölümü
  - Haftanın öne çıkan içerikleri (Bento Grid)
  - Kategori kartları ve makale sayıları
  - Son eklenen blog yazıları
  - Haftanın materyali indirme çağrısı (Teacher Toolkit)

- **📝 Blog & Filtreleme:**
  - Canlı anlık arama (`Ctrl + K`)
  - Kategori hapları (Yapay Zekâ, Ders Materyalleri, Eğitim Teknolojileri, Pedagoji & Rehberlik, Ölçme & Değerlendirme)
  - Sıralama (En Yeniler, Popüler, Beğenilenler)

- **📖 Zengin Okuma Modu (Single Article View):**
  - İndirilebilir materyal önizleme ve indirme kutuları
  - Yazı boyutu ayarlama (`Boyut` butonu)
  - Yer imlerine ekleme (`LocalStorage` destekli)
  - Beğeni sayacı ve tek tıkla bağlantı paylaşımı
  - İlgili diğer makale önerileri

- **🌓 Koyu / Aydınlık Tema (Dark / Light Mode):**
  - Göz yormayan renk kontrastı ve pürüzsüz geçişler.

- **📌 Kaydedilenler Çekmecesi (Bookmarks Drawer):**
  - Beğendiğiniz makaleleri daha sonra okumak üzere saklama.

- **✉️ İletişim & SSS:**
  - Branş seçimli iletişim formu
  - Öğretmenler için Sıkça Sorulan Sorular (SSS) akordeonu.

- **📱 %100 Mobil ve Tablet Uyumlu:**
  - Dokunmatik ekranlar için özel hamburger menü çekmecesi.

## 📁 Proje Yapısı

```
WEB SİTESİ/
├── index.html          # Ana sayfa ve tüm bölümler (SPA mimarisi)
├── styles.css          # Modern CSS3 değişkenleri, koyu tema ve animasyonlar
├── app.js              # Arama, filtreleme, modal, yer imleri ve bildirim mantığı
├── data/
│   └── posts.js        # Örnek blog yazıları, yazarlar, materyaller ve SSS verisi
└── README.md           # Proje dokümantasyonu
```

## 🚀 Kurulum ve Çalıştırma

1. Projeyi bilgisayarınıza klonlayın veya zip olarak indirin:
   ```bash
   git clone https://github.com/eyleminan/ogretmenler-odasi-blog.git
   ```
2. Klasör içindeki `index.html` dosyasını herhangi bir web tarayıcısında çift tıklayarak açın.
3. Herhangi bir harici sunucu veya kütüphane kurulumu gerektirmez.
